## Data-Analysis-and-Visualisation

This repository contains the Colab notebook and supporting data used for the course project on data analysis and visualisation (DLBDSEDAV01).
It provides the code and data used throughout the project.
The used datasets are available at: 
https://www.kaggle.com/datasets/ronikmalhotra/melbourne-housing-dataset


### Repository Structure
| Path | Description |
|------|--------------|
| `data/`| housing and geospatial data|
| `data_visualisation.ipynb/`| Colab notebook |

You can open the notebook directly in Google Colab using the link below:
[Open in Collab](https://colab.research.google.com/github/cewgs/Data-Analysis-and-Visualisation/blob/main/data_visualisation.ipynb)
